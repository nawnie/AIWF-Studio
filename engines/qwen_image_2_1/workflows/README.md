# Reference ComfyUI API workflows for Qwen-Image 2.1

Generated by `python scripts/export_qwen21_workflows.py` from `qwen21/workflow_builder.py`
and validated offline (link integrity + node signatures from ComfyUI 0.39.0 sources).
They are **API-format prompts**: `POST` them to `/prompt` as `{"prompt": <file>, "client_id": ...}`
or drag the JSON onto the ComfyUI canvas (recent frontends convert API prompts).
Each `*.spec.json` holds the GenerationSpec that produced the file; the app can reload it.

All use the 16 GB defaults: `qwen_image_2.1_int8_convrot` + `qwen3vl_8b_int8_convrot` + `qwen_image_2.1_vae_bf16`,
25 steps, CFG 1, euler/simple, PNG with alpha. Reference image names such as `qwen21/portrait.png`
are placeholders for files in `ComfyUI/input/qwen21/` (the app uploads them for you).
